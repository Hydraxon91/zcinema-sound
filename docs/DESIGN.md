# Design notes

Palette and icon artwork for ZCinema Sound, kept out of the main README so it stays
focused on users.

## Palette

| Colour | Hex | Role |
|---|---|---|
| Major (background) | `#010001` | app background |
| Accent | `#D9872C` | primary accent |
| Accent (dark) | `#AE4906` | buttons / selected |
| Edge | `#E1E0E1` | text |
| Minor | `#FAFBCA` | highlights |

## Icon

<img src="assets/ZCinemaSound.png" width="48" alt="icon">

`assets/ZCinemaSound.ico` is an 8-size pack (16/24/32/48/64/96/128/256) used for the
window and tray icon. If the file is missing at runtime, the app falls back to a
system icon.
